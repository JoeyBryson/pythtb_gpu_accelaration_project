# Project Propersal

We create an instance of the Kane-Mele model from pythtb, with thermal fluctuations. We can benchmark against un-optimized code from pythtb, with various different methods of speed ups and cross verify correctness and assumptions against the 2016 paper and it's results. If we have extra time we can also start to speculate further about what the implications of a faster simulation would be and if there are any other scientific lines of research that could be perused as a result of our speed-ups.
